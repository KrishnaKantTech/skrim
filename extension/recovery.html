If you would rather do it by hand

This works with the extension removed, disabled, or broken:

  1. Open the bookmark manager — Ctrl/⌘ + Shift + O.
  2. Click Other bookmarks and look for a folder starting with “Skrim — hidden while screen sharing”. Bookmarks hidden by an older version are under “SecureShare — hidden while screen sharing” instead.
  3. Select everything in it and drag it onto your bookmarks bar. The order inside the folder is the order it was in on the bar.
  4. Delete the placeholder links we put on the bar while it was hidden.
  5. Delete the now-empty folder.

Receipt

Each hidden batch leaves a bookmark inside its folder recording where every item belongs. It survives this extension being uninstalled, which is what makes an exact restore possible afterwards. Open one and this page reads it.
